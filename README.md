# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/9991a3c5-5d31-4c16-afbd-25236af7b212

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app (Express authentication server and Vite):
   `npm run dev`

On this Windows setup, double-click `start.cmd` to use the portable Node.js runtime.
Open http://localhost:3000/. Existing browser accounts migrate on first local startup.

See [IMPLEMENTATION_REPORT.md](IMPLEMENTATION_REPORT.md) for session behavior, validation, production setup, and remaining operational database/security limitations.
